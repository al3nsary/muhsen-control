# مُحسن · الكنترول

غرفة عمليات موسم الحج — **المصدر الأصل** الذي يقرأ منه تطبيق الميدان ويرفع إليه.

```
node app/build.cjs     # يبني control.html و docs/index.html ويشغّل أربعة حُرّاس
```

ثم افتح `control.html` مباشرة — يعمل بلا خادم وبلا إنترنت.

## الحدّ مع تطبيق الميدان

| | المسار |
|---|---|
| تطبيق الميدان | `Desktop/Muhesn-App/` — مستودع مستقل |
| **الكنترول** | `Desktop/Muhsen-Control/` — هذا |

**مشروعان منفصلان.** الرابط بينهما عقدٌ في المفاهيم لا في الشيفرة:
الكنترول يُنشئ المهام والفرق والحجاج والأدلة، والتطبيق يعرضها ويرفع إليه الطلبات والتقارير.

## الوثائق

| الملف | ما فيه |
|---|---|
| `spec/SYSTEM.md` | قواعد العمل — المرجع الذي يُحسم عنده الخلاف |
| `spec/DESIGN.md` | الاتجاه البصري والشاشات المقترحة |
| `spec/SKILLS.md` | ما يجب معرفته قبل الكتابة |
| `spec/CHANGELOG.md` | كل تعديل بتاريخه وسببه |
